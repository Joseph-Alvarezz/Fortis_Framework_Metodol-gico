# Política de seguridad

## Alcance
Este repositorio contiene documentación metodológica y laboratorios formativos. No contiene ni debe contener
credenciales, datos personales, información de terceros ni artefactos que permitan afectar sistemas reales.

## Reportar un problema
Si encuentras en el repositorio un secreto expuesto, un dato sensible o un procedimiento que pueda usarse contra
sistemas no autorizados, **no abras un issue público**. Usa la opción *Report a vulnerability* (pestaña Security)
de GitHub o contacta a los mantenedores por un canal privado.

## Uso responsable
Todo procedimiento descrito aquí debe aplicarse solo sobre sistemas propios o con autorización expresa y escrita,
dentro del alcance y las reglas de compromiso definidas en la fase 01.
