# Fase 06 · Verificación

**Objetivo:** Reejecutar casos comparables y medir la efectividad del tratamiento.

| Elemento | Detalle |
|---|---|
| Entradas | Plan de tratamiento, casos originales, línea base |
| Salida / producto | Informe de efectividad |
| Responsable principal | Evaluador / Coordinador de evaluación |
| Criterio de cierre | Entregables revisados, evidencia identificable y aprobación del coordinador de evaluación |

## Actividades
1. Re-test de casos comparables
2. Comparar con la línea base y la cobertura de detección
3. Aprobar cierre y retroalimentar la siguiente iteración
