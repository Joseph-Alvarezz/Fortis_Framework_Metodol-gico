# Fase 03 · Identificación

**Objetivo:** Ejecutar pruebas autorizadas mientras se monitorea la detección.

| Elemento | Detalle |
|---|---|
| Entradas | Plan, línea base, casos de prueba (anexo A) |
| Salida / producto | Hallazgos documentados con evidencia |
| Responsable principal | Analista ofensivo / Analista defensivo |
| Criterio de cierre | Entregables revisados, evidencia identificable y aprobación del coordinador de evaluación |

## Actividades
1. Ejecutar casos autorizados con bitácora
2. Monitorear alertas y registros en paralelo
3. Preservar evidencias con SHA-256 y cadena de custodia
