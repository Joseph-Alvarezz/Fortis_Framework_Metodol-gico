# FC-LAB-005 · Ingeniería social: principios

| Campo | Descripción / dato requerido |
|---|---|
| Identificador | FC-LAB-005 |
| Nombre y versión | Ingeniería social: principios · v1.0 · noviembre de 2026 |
| Objetivo | Reconocer los principios de persuasión que explota la ingeniería social e identificar sus indicadores en mensajes reales y sintéticos. |
| Dominio y fase | D05 Factor humano · fase 02 Prevención |
| Roles | Ejecutores: todos los participantes · Revisor: evaluador |
| Entorno y autorización | Aula o sesión virtual. No se envían mensajes a personas reales: se trabaja con ejemplos sintéticos o publicados por campañas de concienciación. Autorización escrita requerida antes de ejecutar. |
| Entradas | Conjunto de 10 mensajes sintéticos (correo, SMS, llamada transcrita), algunos legítimos y otros fraudulentos. |
| Procedimiento | Ver [procedimiento.md](procedimiento.md) |
| Evidencias | `evidencias/`, registradas en el anexo C con SHA-256 |
| Criterio de aceptación | Cada participante clasifica correctamente al menos el 80 % de los mensajes y justifica los indicadores. |
| Análisis defensivo | Programas de concienciación, verificación por un segundo canal, autenticación multifactor y procedimientos de reporte. |
| Resultado | Ver [resultados.md](resultados.md) |

Enfoque: Factor humano
