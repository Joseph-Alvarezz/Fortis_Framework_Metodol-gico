# Glosario

| Término | Definición |
|---|---|
| Red Team | Equipo o función que emula comportamientos adversarios de forma autorizada |
| Blue Team | Equipo o función que protege, detecta y responde |
| Purple Team | Coordinación de Red y Blue Team para que cada prueba mejore la detección y los controles |
| SOC | Centro de operaciones de seguridad: monitoreo y gestión de alertas |
| DFIR | Análisis forense digital y respuesta a incidentes |
| Línea base | Medición inicial de controles e indicadores, usada para comparar tras el tratamiento |
| Hallazgo | Debilidad confirmada con evidencia, vinculada a un caso de prueba |
| Re-test | Reejecución de un caso comparable para verificar una corrección |
| Cadena de custodia | Registro de quién obtuvo, manipuló y transfirió cada evidencia, cuándo y cómo |
| Hash SHA-256 | Huella criptográfica que permite comprobar que una evidencia no fue alterada |
| Reglas de compromiso | Límites acordados de alcance, horario, técnicas y contactos de una evaluación |
| RACI | Matriz de asignación: Responsable, Aprueba, Consultado, Informado |
